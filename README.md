#  HardWareMonitor Pro

> WPF-приложение для мониторинга и диагностики аппаратного обеспечения компьютера в реальном времени


---

##  Описание

HardwareMonitor - приложение для комплексного мониторинга аппаратного обеспечения ПК.  
Получает данные о процессоре, оперативной памяти, дисках и запущенных процессах через технологию WMI (Windows Management Instrumentation) и отображает их на базе WPF.

Разработано в рамках лабораторной работы по дисциплине «Системное программное обеспечение».

---

##  Цель лабораторной работы

Разработать WPF-приложение для комплексного мониторинга аппаратного обеспечения с использованием WMI и паттерна MVVM.

---

##  Задачи

- Освоить работу с WMI в C# через библиотеку System.Management
- Получать данные об аппаратном обеспечении: процессор, память, диски
- Реализовать обновление данных в реальном времени без блокировки UI
- Разработать интерфейс с использованием WPF и паттерна MVVM
- Освоить многопоточность (async/await + Task.Run) для фоновых запросов
- Обеспечить обработку исключений и отзывчивость приложения

---

## Функциональность

###  Процессор (CPU)
- Модель, производитель, архитектура
- Количество ядер и потоков
- Базовая частота (МГц)
- Текущая загрузка в %

###  Оперативная память (RAM)
- Общий объём и доступный объём
- Процент использования
- Список модулей: производитель, объём, частота

###  Диски
- Физические диски: модель, размер, тип носителя
- Логические диски: буква, общий/свободный объём, % использования

###  Видеокарта (GPU)
- Модель видеокарты
- Видеопамять

### СЕТЬ
- Информация о сетевом адаптере
- MAC-адрес
- Скорость

### Диспетчер задач
- ID процесса и его имя
- Память в байтах и МБ

###  Экспорт
- Экспорт полной информации о системе в .txt
- Экспорт полной информации о системе в .CSV
- Экспорт полной информации о системе в .json

##  Структура проекта

- **HardWareMonitor/**
  - **Models/# Модели данных**
    - `CpuInfo.cs` - Данные о процессоре
    - `MemoryInfo.cs` - Данные об оперативной памяти
    - `DiskInfo.cs` - Данные о дисках
    - `SystemInfo.cs` - Системная информация
    - `GpuInfo.cs` - Данные о видеокарте
    - `NetworkAdapterInfo.cs` - Сетевой адаптер
  - **Services/# Сервисы получения данных через WMI**
    - `CpuMonitor.cs` - Мониторинг процессора
    - `MemoryMonitor.cs` - Мониторинг памяти
    - `DiskMonitor.cs` - Мониторинг дисков
    - `ProcessMonitor.cs` - Мониторинг процессов
    - `SystemMonitor.cs` - Мониторинг операционной системы
    - `NetworkMonitor.cs` - Мониторинг сети
    - `GpuMonitor.cs` - Мониторинг видеокарты
  - **ViewModels/# MVVM-логика**
    - `BaseViewModel.cs` - Базовый класс с INotifyPropertyChanged
    - `MainViewModel.cs` - Главная ViewModel
    - `RelayCommand.cs` - Реализация ICommand
  - **Views/# Интерфейс пользователя**
    - `MainWindow.xaml` - Основной интерфейс
    - `MainWindow.xaml.cs` - Code-behind главного окна
  - **Utils/# Утилиты**
    - `ExportService.cs` - Экспорт в .txt, .json, .csv
  - `App.xaml` - Точка входа приложения
  - `App.xaml.cs` - Code-behind приложения
    
##  Как использовать

1. Запусти приложение
2. Данные загружаются автоматически при старте
3. Переключайся между вкладками: Процессор / Память / Диски / Сетевые адаптеры / Видеокарта / Диспетчер задач
4. Нажми "Обновить" в нижней части интерфейса для ручного обновления
5. Нажми зеленую кнопку "Обновить" для обновления данных
6. В верхней части интерфейса нажми красную кнопку «Стоп» для завершения обновления информации
7. Кнопка «Экспорт TXT» сохранит отчёт в .txt
8. Кнопка «Экспорт CSV» сохранит отчет в .CSV
9. Кнопка «Экспорт JSON» сохранит отчёт в .json
